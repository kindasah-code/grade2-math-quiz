# رحلة العلوم — الوحدة الأولى: المخلوقات الحية

مذكرة تفاعلية إثرائية باللغة العربية لطلاب **الصف الرابع الابتدائي** في السعودية، الجزء الأول من مقرر العلوم.

## رابط المذكرة

https://kindasah-code.github.io/grade2-math-quiz/science-grade4/

## النطاق

- الفصل الأول — ممالك المخلوقات الحية:
  - الخلايا
  - تصنيف المخلوقات الحية
- الفصل الثاني — المملكة الحيوانية:
  - الحيوانات اللافقارية
  - الحيوانات الفقارية
  - أجهزة أجسام الحيوانات

## المزايا

- خمسة دروس تتضمن شروحًا مبسّطة ورسومات توضيحية أصلية مبنية بـ HTML وCSS ومقارنات وجداول وأمثلة.
- سؤال تفاعلي في نهاية كل درس يسجّل الإنجاز عند الإجابة الصحيحة.
- ٢٥ بطاقة لمراجعة المفاهيم والمصطلحات مع كشف الإجابة.
- اختبار نهائي من ٢٥ سؤالًا، بواقع خمسة لكل درس، مع تصحيح فوري وتفسير وحفظ النتيجة ومراجعة تفصيلية.
- ترتيب مختلف للأسئلة في كل محاولة، دون مؤقّت.
- واجهة متجاوبة بالعربية واتجاه من اليمين إلى اليسار، تعمل على الهاتف والكمبيوتر.
- حفظ تقدم المذاكرة والاختبار محليًا على الجهاز (localStorage)، دون حساب أو إرسال الإجابات.
- لا تحتاج المكتبات البرمجية إلى خادم أو عملية بناء؛ يحتوي المجلد على ملفات HTML وCSS وJavaScript فقط.

## مرجع الموضوعات

تمت مواءمة تسلسل الدروس مع فهرس كتاب العلوم رابع ابتدائي الجزء الأول، الوحدة الأولى (طبعة 1448 هـ)، بمراجعة مراجع تعليمية للمنهج السعودي. المحتوى **صياغة إثرائية مبسّطة** ولا يحل محل الكتاب الرسمي أو يقتبس صفحاته.

## الملفات

- `index.html` — الصفحة الرئيسية والتنقل.
- `styles.css` — التنسيق والرسوم المتجهة المصنوعة بتنسيق CSS والتجاوب.
- `app.js` — محتوى الدروس والأنشطة وبطاقات المفاهيم وأسئلة الاختبار وحفظ التقدم.

## GitHub Pages

الموقع منشور بوصفه مجلدًا فرعيًا من مستودع `grade2-math-quiz` (فرع `main`، الجذر)، باستخدام إعداد GitHub Pages الموجود بالمستودع.

## ملاحظات تربوية

- الرسوم التخطيطية للخلية مبسطة وغير مقياسية.
- تجميع الفقاريات إلى خمس مجموعات هنا لأغراض التمهيد؛ يحتوي التصنيف التفصيلي لبعض المجموعات، وخاصة الأسماك، على تقسيمات فرعية أخرى.
- الأسئلة أصلية للتدريب، وليست نموذجًا وزاريًا رسميًا.
