# رحلة الأعداد — رياضيات الصف الثاني

اختبار عربي متجاوب للصف الثاني الابتدائي، يغطي موضوعات الفصل الأول **القيمة المنزلية حتى ١٠٠ والأنماط** والفصل الثاني **طرائق الجمع** المحددة في الطلب. الأسئلة أصلية، والموقع تدريب إثرائي مستقل وليس إصدارًا رسميًا من وزارة التعليم.

## المميزات

- ٢٠ سؤالًا ثابتًا متنوعًا: ١٠ لكل فصل، باختيار الإجابة أو كتابة العدد.
- تمثيل بصري بالعشرات والآحاد، خط الأعداد، المجموعات، وإطار العشرة.
- تصحيح وشرح مباشر بعد تأكيد الإجابة. لا ينتقل الموقع تلقائيًا للسؤال التالي.
- تُسجّل الإجابة الأولى المؤكدة، نقطة لكل سؤال، دون خصم مقابل التلميحات.
- نتيجة مفصّلة بحسب الفصل، ومراجعة لكل سؤال مع الإجابة والشرح.
- حفظ المحاولة في المتصفح، استئنافها، إعادة الاختبار، وطباعة التقرير.
- واجهة عربية RTL متجاوبة، دعم لوحة المفاتيح والأرقام العربية والإنجليزية، وأوصاف نصية للرسومات.
- لا أسماء، ولا حسابات، ولا تحليلات أو مكتبات خارجية. لا تُرسل الإجابات إلى خادم.

## الملفات والتشغيل

افتح `index.html` مباشرة، أو شغّل أي خادم ملفات ثابتة في هذا المجلد. لا حاجة إلى تثبيت اعتماديات أو عملية بناء.

- `questions.js`: الأسئلة والإجابات ومنطق احتساب الدرجة.
- `app.js`: التفاعل والمساعدة البصرية وحفظ التقدّم.
- `styles.css`: التصميم والتجاوب والطباعة.

## GitHub Pages

مصدر النشر: الفرع `main`، المجلد `/ (root)`. وجود `.nojekyll` يجعل النشر ثابتًا دون معالجة Jekyll.

## نطاق الأسئلة

القيمة المنزلية والتمثيل، الصورة التحليلية، قراءة الأعداد، المقارنة والترتيب، العدد مئة، العد القفزي والأنماط المتكررة؛ ثم الجمع مع الصفر، تبديل العددين، العد التصاعدي، المسائل بالرسم، جمع العدد ونفسه، جمع العدد ونفسه مضافًا إليه ١، تكوين العشرة، جمع ثلاثة أعداد، وإكمال العدد المفقود.

## الخصوصية

يحفظ الموقع المحاولة في `localStorage` على جهاز المستخدم. بدء محاولة جديدة يستبدل القديمة بعد التأكيد. زر المشاركة ينسخ رابط الاختبار فقط، دون الإجابات أو النتيجة. يخضع تسليم صفحات الموقع إلى سياسات خدمة GitHub Pages المعتادة.
